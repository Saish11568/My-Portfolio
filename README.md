# Saish Malalikar — Portfolio

A minimal, editorial developer portfolio for **Saish Malalikar**, Computer Science and Engineering student. Built with Next.js (App Router), TypeScript, Tailwind CSS, and Framer Motion.

## 🏛️ Design Vision & Editorial Language

- **Palette**: Warm ivory parchment background (`#FBF9F4`), deep editorial teal accent (`#0F4C4C`), near-black charcoal typography (`#181A1C`), and delicate hairline dividers (`#E5DFD3`).
- **Typography**: Editorial serif typography (`Newsreader`) paired with clean sans-serif text (`Inter`) for crisp legibility and sophisticated presentation.
- **Tone**: Calm, intentional, and content-first—prioritizing engineering problem descriptions and real project implementations over flashy neon gradients and oversized decorative clutter.

## 🚀 Key Projects Featured

1. **BusTrack** — Real-time public transit tracking system for passengers and transport management.
2. **AgriSmart / FarmChain** — Agricultural supply chain transparency and batch ID produce traceability.
3. **PrintShop** — Role-based full-stack print shop management system for academic and commercial printing.
4. **Vendor Marketplace** — Multi-vendor catalog and direct merchant commerce interface.
5. **Zero Hunger** — Surplus food redistribution coordination platform.

## 🛠️ Stack & Technologies

- **Framework**: Next.js 16 (App Router, Turbopack)
- **UI Library**: React 19
- **Typography**: Google Fonts via `next/font/google` (`Newsreader`, `Inter`)
- **Styling**: Tailwind CSS v4 & PostCSS
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Contact Service**: EmailJS Browser Integration

## 💻 Local Development Setup

1. **Prerequisites**: Node.js 18+ or 20+ (Node.js LTS 24 installed).
2. **Install Dependencies**:
   ```bash
   npm install
   ```
3. **Run Development Server**:
   ```bash
   npm run dev
   ```
4. **Open in Browser**:
   Navigate to [http://localhost:3000](http://localhost:3000).

5. **Production Build**:
   ```bash
   npm run build
   ```

## ☁️ Deployment Guide (Vercel)

Deploying this portfolio to [Vercel](https://vercel.com) takes less than 2 minutes:

### Option 1: Via GitHub & Vercel Dashboard (Recommended)
1. Push your repository to GitHub:
   ```bash
   git init
   git add .
   git commit -m "feat: premium editorial portfolio redesign"
   git remote add origin https://github.com/Saish11568/My-Portfolio.git
   git push -u origin main
   ```
2. Go to [vercel.com/new](https://vercel.com/new).
3. Import your `My-Portfolio` repository.
4. Framework Preset will automatically detect **Next.js**.
5. Root Directory: `./` (leave default).
6. Click **Deploy**. Vercel will build and deploy your site to a global CDN.

### Option 2: Via Vercel CLI
1. Install Vercel CLI globally:
   ```bash
   npm i -g vercel
   ```
2. Run deployment command in the project directory:
   ```bash
   vercel
   ```
3. Follow the CLI prompts to link and deploy to production (`vercel --prod`).
